# 빅보이 튜토리얼 대사와 음성

대사 원본은 프로젝트 루트의 `tutorial-story.js`에 있습니다. 각 대사는 고유한 `id`, 표시 문구 `text`, 녹음 파일 경로 `voiceSrc`를 가집니다. `{name}`은 플레이어가 정한 닉네임으로 치환됩니다.

음성 파일이 준비되면 해당 대사의 `voiceSrc`에 프로젝트 기준 상대 경로를 넣습니다. 예를 들어 `welcome` 대사를 `{ id: 'welcome', text: '너가 이번에 새로 들어왔다는 신입이냐.', voiceSrc: 'tutorial-screen/dialogue/voice/welcome.wav' }`로 바꾸면 됩니다. `null`인 대사는 자막만 출력합니다.

음성은 대사가 표시될 때 재생되며, 다음 대사·재시도·스킵·튜토리얼 종료 시 이전 음성이 중단됩니다. 설정창의 효과음 볼륨을 따릅니다. 닉네임이 포함된 대사는 녹음에 실제 닉네임을 넣지 않아도 자막에는 닉네임이 표시됩니다.

튜토리얼은 발사, 상대 밀어내기, 총알 장전 사용, 방출 트리거 활용의 네 단계입니다. 계정에는 `tutorialCompleted`가 저장되며 재배치와 모험 해금 상태는 이 기록에서 결정됩니다. 게스트의 완료 기록은 현재 접속 중에만 유지됩니다. 모험 스테이지 콘텐츠는 별도 구현 대상이며, 이번 튜토리얼은 해금 기록과 보상 연출을 제공합니다.
